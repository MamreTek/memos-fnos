# 项目差异与约定

- REQ-001 已于 2026-11-12 确认，跟踪于 Issue #1；实现只在对应 Issue 分支，完成验证后走 PR。需求保存在仓库外，绑定保存在全局 Mamre 记录中。
- 本项目封装已有完整 Memos 服务，不新建 Web 应用或重写前端；不额外引入 React/Ant Design 原型、Mock、数据库服务或账号系统。
- 使用官方 Docker 多架构镜像及固定 digest，一个架构无关 .fpk。数据路径由 fnOS 资源声明解析，禁止硬编码存储卷。
- Bash 与 NAS 基础工具处理生命周期；容器以数字应用 UID/GID 直接运行，避开上游 root 入口的递归 chown。fnOS ACL 行为待实机核实。
- 默认端口 5230，桌面 URL 入口打开独立浏览器页。首版不增加端口配置、单点登录或公网入口。
- 本地 Docker 需交互式 sudo，不能用于本次集成测试；使用 GitHub 托管 runner 执行真实 amd64/arm64 容器测试，通过后 PR 才 ready。ARM64 QEMU 与 fnOS 实机结果分别记录。
- 候选包不设置未经验证的最小系统版本；正式发布前完成实机矩阵并设置可证明的兼容范围。
